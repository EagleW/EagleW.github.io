<b>[SciMON: Scientific Inspiration Machines Optimized for Novelty](https://eaglew.github.io/dataset/scimon)</b> ![GitHub Repo stars](https://img.shields.io/github/stars/EagleW/Scientific-Inspiration-Machines-Optimized-for-Novelty?style=social)<br>
This repositiory contains datasets for SciMon Paper. The NLP dataset is based on 67,409 ACL anthology papers from 1952 to 2022. The biomedical dataset is based on 5,704 papers from PubMed. [[Paper]](https://arxiv.org/abs/2305.14259) [[Code/Dataset]](https://github.com/EagleW/Scientific-Inspiration-Machines-Optimized-for-Novelty) [[Slides]](https://eaglew.github.io/files/SciMON_ACL.pdf) [[Poster]](https://eaglew.github.io/files/ACL2024-poster.pdf)  

<b>[Chem-FINESE: Validating Fine-Grained Few-shot Entity Extraction through Text Reconstruction](https://eaglew.github.io/dataset/chemf)</b>
![GitHub Repo stars](https://img.shields.io/github/stars/EagleW/Chem-FINESE?style=social)<br>
This repositiory contains two chemical few-shot fine-grained entity extraction dataset based on ChemNER and CHEMET. We choose the values 6, 9, 12, 15, 18 as the potential maximum entity mentions for k-shot for both datasets. [[Paper]](https://arxiv.org/abs/2401.10189) [[Code]](https://github.com/EagleW/Chem-FINESE) [[Dataset]](https://github.com/EagleW/Chem-FINESE/tree/main/data) 

<b>[Multimedia Goal-oriented Generative Script Learning Dataset](https://eaglew.github.io/dataset/multi)</b> ![GitHub Repo stars](https://img.shields.io/github/stars/EagleW/Multimedia-Generative-Script-Learning?style=social)<br>
This repository contains 5,652 tasks and 79,089 multimedia steps for gardening (Training: 20,258/Development: 2,428/Test: 2,684) and crafts category (Training: 32,082/Development: 4,064/Test: 3,937). [[Paper]](https://aclanthology.org/2023.findings-acl.63.pdf) [[Code]](https://github.com/EagleW/Multimedia-Generative-Script-Learning-for-Task-Planning) [[Dataset]](https://drive.google.com/file/d/1lSo-Kr4edNas0_uTl1SvDnEGuPYl0Or9/view?usp=sharing) [[Bib]](https://aclanthology.org/2023.findings-acl.63.bib)

<b>[Wikipedia Pre-train Pairs Dataset](https://eaglew.github.io/dataset/stage)</b> ![GitHub Repo stars](https://img.shields.io/github/stars/EagleW/Stage-wise-Fine-tuning?style=social)<br>
[![PWC](https://img.shields.io/endpoint.svg?url=https://paperswithcode.com/badge/stage-wise-fine-tuning-for-graph-to-text/data-to-text-generation-on-webnlg-full-1)](https://paperswithcode.com/sota/data-to-text-generation-on-webnlg-full-1?p=stage-wise-fine-tuning-for-graph-to-text)<br>
This repository contains 542,192 data pairs used for the Wikipedia fine-tuning stage . The data folder contains 166 JSON files which include graph-to-text pairs related to 15 categories (Astronaut, University, Monument, Building, ComicsCharacter, Food, Airport, SportsTeam, WrittenWork, Athlete, Artist, City, MeanOfTransportation, CelestialBody, Politician) that appear in the WebNLG dataset.  [[Paper]](https://aclanthology.org/2021.acl-srw.2.pdf) [[Code]](https://github.com/EagleW/Stage-wise-Fine-tuning) [[Dataset]](https://drive.google.com/file/d/18N8xgAftgoV7D03G643EDp1BfQXzPOTH/view?usp=sharing) [[Slides]](https://eaglew.github.io/files/stage_slides.pdf) [[Poster]](https://eaglew.github.io/files/stage-poster.pdf) [[Bib]](https://aclanthology.org/2021.acl-srw.2.bib)

<b>[ReviewRobot Dataset](https://eaglew.github.io/dataset/reviewrobot)</b> ![GitHub Repo stars](https://img.shields.io/github/stars/EagleW/ReviewRobot?style=social)<br>
This dataset contains 8,110 paper and review pairs and background KG from 174,165 papers. It also contains information extraction results from [SciIE](https://bitbucket.org/luanyi/scierc/src/master/) and various knowledge graph built on the IE results. The detailed information can be found [here](https://github.com/EagleW/ReviewRobot/blob/master/dataset/README.md). [[Paper]](https://aclanthology.org/2020.inlg-1.44.pdf) [[Dataset]](https://drive.google.com/file/d/1NclEwGEVcHCrSWk8s3lDjvEbMlWXQoXM/view?usp=sharing) [[Bib]](https://aclanthology.org/2020.inlg-1.44.bib)


<b>[Covid-KG](http://blender.cs.illinois.edu/covid19/)</b><br>
This dataset currently gathers knowledge extraction result from 14,229 papers and 6217 abstracts about [Semantic Scholar's CORD-19 Dataset](https://allenai.org/data/cord-19), <b>[Best Demo Award at NAACL-HLT 2021](https://2021.naacl.org/blog/best-demo-award/)</b>. [[Paper]](https://aclanthology.org/2021.naacl-demos.8.pdf) [[KG]](http://blender.cs.illinois.edu/covid19/)

<b>[PubMed Paper Reading Dataset](https://eaglew.github.io/dataset/paperrobot_reading)</b> ![GitHub Repo stars](https://img.shields.io/github/stars/EagleW/PaperRobot?style=social)<br>
This dataset gathers 14,857 entities, 133 relations, and entities corresponding tokenized text from PubMed. It contains 875,698 training pairs, 109,462 development pairs, and 109,462 test pairs. [[Paper]](https://aclanthology.org/P19-1191) [[Bib]](https://aclanthology.org/P19-1191.bib) [[Dataset]](https://drive.google.com/open?id=1DLmxK5x7m8bDPK5ZfAROtGpkWZ_v980Z)

<b>[PubMed Term, Abstract, Conclusion, Title Dataset](https://eaglew.github.io/dataset/paperrobot_writing)</b> ![GitHub Repo stars](https://img.shields.io/github/stars/EagleW/PaperRobot?style=social)<br>
This dataset gathers three types of pairs: Title-to-Abstract (Training: 22,811/Development: 2095/Test: 2095), Abstract-to-Conclusion and Future work (Training: 22,811/Development: 2095/Test: 2095), Conclusion and Future work-to-Title (Training: 15,902/Development: 2095/Test: 2095) from PubMed. Each pair contains a pair of input and output as well as the corresponding terms(from original KB and link prediction results). [[Paper]](https://aclanthology.org/P19-1191) [[Bib]](https://aclanthology.org/P19-1191.bib) [[Dataset]](https://drive.google.com/open?id=1O91gX2maPHdIRUb9DdZmUOI5issRMXMY)

<b>[Wikipedia Person and Animal Dataset](https://eaglew.github.io/dataset/narrating)</b> ![GitHub Repo stars](https://img.shields.io/github/stars/EagleW/Describing_a_Knowledge_Base?style=social)<br>
This dataset gathers 428,748 person and 12,236 animal infobox with descriptions based on Wikipedia dump (2018/04/01) and Wikidata (2018/04/12). [[Paper]](http://aclanthology.org/W18-6502) [[Bib]](https://aclanthology.org/W18-6502.bib) [[Dataset]](https://drive.google.com/open?id=1TzcNdjZ0EsLh_rC1pBC7dU70jINcsVJd)

<b>[ACL Title and Abstract Dataset](https://eaglew.github.io/dataset/Writing-editing)</b> ![GitHub Repo stars](https://img.shields.io/github/stars/EagleW/Writing-editing-Network?style=social)<br>
This dataset gathers 10,874 title and abstract pairs from the ACL Anthology Network (until 2016). [[Paper]](https://eaglew.github.io/publication/Writing-editing) [[Bib]](https://aclanthology.org/P18-2042.bib) [[Dataset]](https://github.com/EagleW/ACL_titles_abstracts_dataset)
