This repository contains 542,192 data pairs used for the Wikipedia fine-tuning stage. The data folder contains 166 JSON files which include graph-to-text pairs related to 15 categories (Astronaut, University, Monument, Building, ComicsCharacter, Food, Airport, SportsTeam, WrittenWork, Athlete, Artist, City, MeanOfTransportation, CelestialBody, Politician) that appear in the WebNLG dataset. The detailed information can be found [here](https://github.com/EagleW/Stage-wise-Fine-tuning/tree/main/Wikipedia%20Pre-train%20Pairs).
