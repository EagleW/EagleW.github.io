This dataset contains 8,110 paper and review pairs and background KG from 174,165 papers. It also contains information extraction results from [SciIE](https://bitbucket.org/luanyi/scierc/src/master/), various knowledge graphs built on the IE results, and human annotation for paper-review pairs.  The detailed information can be found [here](https://github.com/EagleW/ReviewRobot/blob/master/dataset/README.md).
